# 🗺️ Trilhas de Aprendizado - Monitoria Web

Para quem não sabe por onde começar, siga estas trilhas. Não tente aprender tudo de uma vez; foque em construir projetos pequenos em cada etapa.

---

## 🟢 Trilha 1: O Básico do Básico (HTML)
**Objetivo:** Criar a estrutura de qualquer página web.

1. **O que é a Web?** $\rightarrow$ Entender a relação Cliente (Browser) $\leftrightarrow$ Servidor.
2. **Estrutura Básica** $\rightarrow$ `<!DOCTYPE html>`, `<html>`, `<head>` e `<body>`.
3. **Tags de Texto** $\rightarrow$ Títulos (`h1-h6`), parágrafos (`p`), listas (`ul`, `ol`, `li`).
4. **Links e Imagens** $\rightarrow$ Atributos `href` e `src`, e a importância do `alt`.
5. **Formulários** $\rightarrow$ `input`, `label`, `button` e `select`.
6. **Semântica** $\rightarrow$ Trocar `div` por `header`, `main`, `footer`, `section` e `article`.

**🎯 Projeto Final da Trilha:** Criar uma página de currículo ou um portfólio simples apenas com HTML.

---

## 🔵 Trilha 2: Estilizando a Web (CSS)
**Objetivo:** Deixar a página visualmente atraente e profissional.

1. **Seletores e Cores** $\rightarrow$ Como selecionar elementos (ID, Classe, Tag) e usar cores (HEX, RGB, HSL).
2. **Box Model** $\rightarrow$ Entender `margin`, `border`, `padding` e `width/height`.
3. **Tipografia** $\rightarrow$ Importar fontes do Google Fonts, `font-size`, `font-weight` e `line-height`.
4. **Posicionamento** $\rightarrow$ Diferença entre `static`, `relative`, `absolute` e `fixed`.
5. **Flexbox (Essencial)** $\rightarrow$ `display: flex`, `justify-content` e `align-items`.
6. **CSS Grid** $\rightarrow$ Layouts complexos com `grid-template-columns`.
7. **Responsividade** $\rightarrow$ Uso de `@media queries` e a mentalidade *Mobile First*.

**🎯 Projeto Final da Trilha:** Transformar o currículo da Trilha 1 em um site moderno, responsivo e com layout Flexbox/Grid.

---

## 🟡 Trilha 3: Tornando a Web Viva (JavaScript)
**Objetivo:** Adicionar interatividade e lógica ao site.

1. **Sintaxe Básica** $\rightarrow$ Variáveis (`let`, `const`), tipos de dados e operadores.
2. **Estruturas de Controle** $\rightarrow$ Condicionais (`if/else`, `switch`) e Laços (`for`, `while`).
3. **Funções** $\rightarrow$ Criação de funções, parâmetros e retorno.
4. **DOM (Document Object Model)** $\rightarrow$ Como selecionar elementos do HTML com JS (`querySelector`) e alterar seu conteúdo/estilo.
5. **Eventos** $\rightarrow$ Capturar cliques, envios de formulário e digitação (`addEventListener`).
6. **Arrays e Objetos** $\rightarrow$ Manipulação de listas de dados e objetos complexos.
7. **Consumo de APIs (Async/Await)** $\rightarrow$ Buscar dados de outros sites usando `fetch`.

**🎯 Projeto Final da Trilha:** Criar uma "Lista de Tarefas" (Todo List) ou um "Conversor de Moedas" que utilize API real.

---

## 🚀 Próximos Passos (Além da Monitoria)
Quando estiver confortável com as três trilhas, explore:
- **Frameworks de CSS:** Tailwind CSS ou Bootstrap.
- **Frameworks de JS:** React, Vue ou Angular.
- **Backend:** Node.js, Python (Django/Flask) ou PHP.
- **Bancos de Dados:** MongoDB ou PostgreSQL.
