## 🔗 Links Úteis

Abaixo estão alguns links recomendados para auxiliar nos estudos e no desenvolvimento e também uma pequena descrição de onde esses links podem ser úteis:

- [DevDocs](https://devdocs.io/) - Documentação combinada para diversas linguagens e frameworks, útil para todas as matérias que envolvem programação.
- [Free APIs](https://free-apis.github.io/#/browse) - Uma lista de APIs gratuitas para user em projetos, útil para PI.
- [BrasilAPI](https://brasilapi.com.br/) - APIs com dados públicos do Brasil, útil para PI.
- [Kultivi](https://kultivi.com/) - Cursos online gratuitos em diversas áreas, útil para horas complementares.
