# Monitoria Web 2026

Este repositório contém materiais e informações úteis para a monitoria de Web 2026.

## 🔗 Links Úteis

Abaixo estão alguns links recomendados para auxiliar nos estudos e no desenvolvimento:

- [DevDocs](https://devdocs.io/) - Documentação combinada para diversas linguagens e frameworks.
- [Free APIs](https://free-apis.github.io/#/browse) - Uma lista de APIs gratuitas para praticar a integração de dados.
- [BrasilAPI](https://brasilapi.com.br/) - APIs com dados públicos do Brasil.
- [Kultivi](https://kultivi.com/) - Cursos online gratuitos em diversas áreas.
